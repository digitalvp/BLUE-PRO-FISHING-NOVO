# BLUE PRO FISHING — CONTEXTO COMPLETO DO PROJETO

## 1. OBJETIVO

Reconstruir e evoluir o site da **Blue Pro Fishing**, utilizando o site atual como referência visual e estrutural.

O site baixado atualmente utiliza **React + Tailwind + JavaScript compilado/minificado**. O HTML basicamente carrega os scripts e monta a aplicação dentro de `#root`.

A nova versão deverá ser reconstruída utilizando uma estrutura mais simples e fácil de editar:

```text
blue-pro-fishing/
│
├── index.html
├── style.css
├── script.js
│
└── assets/
    ├── img/
    ├── logos/
    ├── icons/
    └── fonts/
```

### Regra principal

Não trabalhar diretamente sobre o `script1.js` minificado.

Os arquivos antigos devem servir como **referência para reconstrução**.

# 25. PRINCÍPIO DO PROJETO

O site deve continuar visualmente profissional, porém seu código deverá ser suficientemente simples para que seja possível abrir:

```text
index.html
style.css
script.js
```

e entender rapidamente onde alterar cada parte.

Evitar complexidade desnecessária.

Não alterar grandes partes do projeto sem primeiro entender o efeito no restante do site.

Sempre preservar uma versão funcional antes de alterações estruturais grandes.
